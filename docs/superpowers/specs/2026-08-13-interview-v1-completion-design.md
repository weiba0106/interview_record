# 面试记录平台 V1 完整实现设计

## 目标

以 PRD、V1 路线图和 `AGENTS.md` 为唯一产品与工程基准，将当前已有的认证、公司、岗位、面试轮次、日程和工作台实现整理为可发布的 V1，并补齐提醒、分享、统计、导出和完整主题体验。

## 设计原则

- 现有代码只作为候选实现；与 PRD 或 `AGENTS.md` 冲突时重写。
- 所有业务数据按当前登录用户隔离，服务端不信任客户端 `userId`。
- 所有结构变更使用 Flyway；时间保存 UTC，展示和提醒使用用户时区。
- 删除、分享、导出、提醒和认证按高风险路径编写失败测试。
- 桌面端以左侧导航和高密度工作区为主，移动端在 375px 宽度保持核心流程可完成。

## 产品范围

### 核心工作区

- 工作台显示未归档岗位数、进行中岗位数、未来 7 天待处理日程数和 Offer 数量。
- 公司列表支持公司详情和多岗位关系。
- 岗位列表支持关键词、公司、招聘类型、状态、归档筛选，分页、排序和就地改状态。
- 岗位详情支持多轮面试、面试题/回答、过程记录、复盘和关联日程。
- 日程支持六类 PRD 类型、完成/取消、自动紧急程度和手动覆盖。

### 完整 V1

- 提醒：数据库持久化、唯一幂等键、抢占、取消、最多三次重试和失败状态。
- 分享：哈希令牌、字段/轮次白名单、过期和撤销、匿名只读 `noindex` 页面。
- 统计：状态分布、招聘类型、投递趋势、面试轮次和 PRD 规定的三个转化率。
- 导出：UTF-8 BOM CSV ZIP 和不包含密钥/会话/令牌的 JSON 备份。
- 主题：原始靛蓝、森林青绿、暖杏棕、石墨灰珊瑚红；默认石墨灰珊瑚红，设置后立即生效并持久化。

## 架构

后端继续使用 Spring Boot 模块化单体。新增能力分别放在 `reminders`、`sharing`、`insights` 和 `export` 模块，通过应用服务调用现有领域服务，禁止直接跨模块访问对方表。前端保留按 feature 划分的 API、组件和视图，增加统一 `AppShell`、设计令牌和可访问状态组件。

数据库新增迁移不得修改 V1-V4；新增提醒、分享和导出下载令牌表使用 `user_id`、外键、唯一幂等键和高频查询索引。导出下载使用短期、一次性服务端令牌，不把业务数据放在 URL 中。

## 验收标准

- 本人可访问、其他用户不可访问、未登录不可访问的测试覆盖每个受保护资源。
- 24 小时和 72 小时边界、手动紧急程度、时区和提醒幂等测试通过。
- 分享只能返回创建时选择的字段，过期/撤销/删除后不可读。
- 导出不含密码散列、会话、验证令牌、重置令牌和邮件内部信息。
- 前端单元测试、类型检查、生产构建通过；桌面和 375px 核心页面可操作。
- 运行文档中的启动、迁移和验证命令与实现一致。
